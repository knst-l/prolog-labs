# Лабораторная работа 1

Условие:

Формализовать набор фраз естественного языка в виде программы на языке Prolog.

Флэш — собака. Ровер — собака. Бутси — кошка. Стар — лошадь.
Флэш черная. Бутси коричневая. Ровер рыжая. Стар белая.
Домашнее животное — собака или кошка. Животное — домашнее животное или лошадь.
У Тома есть собака не черного цвета.
У Кейта есть лошадь или что-то черного цвета.

Файл с программой: solution.pl

Запрос:
color(rover, red).

Результат:
true.

Запрос:
dog(X).

Результат:
X = flash ;
X = rover.

Запрос:
owner(Who, What).

Результат:
Who = tom,
What = rover ;

Who = kate,
What = star ;

Who = kate,
What = flash.

Запрос:
owner(Who, X), animal(X), color(X, C), C \= white.

Результат:
Who = tom,
X = rover,
C = red ;

Who = kate,
X = flash,
C = black.
