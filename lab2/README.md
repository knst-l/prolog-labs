# Лабораторная работа 2

Условие:

Создание предикатов для обработки списков.

Вариант 6:
Слить два упорядоченных списка в один, сохранив упорядоченность.

В работе реализованы два отношения:

1. merge/3 — слияние двух упорядоченных списков в один упорядоченный список.
2. merge_sort/2 — сортировка списка методом слияния на основе отношения merge/3.

Файл с программой: solution.pl

Запрос:
merge([1, 3, 5], [2, 4, 6], X).

Результат:
X = [1, 2, 3, 4, 5, 6].

Запрос:
merge([1, 2, 7], [3, 4, 5], X).

Результат:
X = [1, 2, 3, 4, 5, 7].

Запрос:
merge([], [2, 4, 6], X).

Результат:
X = [2, 4, 6].

Запрос:
merge([1, 3, 5], [2, 4, 6], [1, 2, 3, 4, 5, 6]).

Результат:
true.

Запрос:
merge_sort([5, 1, 4, 2, 3], X).

Результат:
X = [1, 2, 3, 4, 5].

Запрос:
merge_sort([7, 3, 7, 1, 4], X).

Результат:
X = [1, 3, 4, 7, 7].

Декларативная интерпретация:

merge(L1, L2, L3) истинно, если L3 является упорядоченным списком, полученным слиянием упорядоченных списков L1 и L2.

merge_sort(L, S) истинно, если S является упорядоченным списком, полученным сортировкой списка L методом слияния.

Процедурная интерпретация:

Чтобы выполнить merge/3, нужно сравнивать первые элементы двух списков. Меньший элемент переносится в результат, затем слияние продолжается для оставшихся элементов. Если один список пуст, результатом является второй список.

Чтобы выполнить merge_sort/2, нужно разделить исходный список на две части, отсортировать каждую часть рекурсивно, а затем слить две отсортированные части с помощью merge/3.
