# Лабораторные работы

Репозиторий содержит лабораторные работы по рекурсивно-логическому программированию и экспертным системам.

## Содержание

- `lab1` — формализация фраз естественного языка на Prolog.
- `lab2` — обработка списков на Prolog.
- `lab3` — поиск кратчайшего пути в графе на Prolog.
- `lab4` — экспертная система подбора хобби на CLIPS.
